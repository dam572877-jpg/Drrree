# FAYOUM ESTATE — نظام إدارة عقارات الفيوم

مشروع Mobile-first مستوحى من مرجع التصميم المرفق: واجهة داكنة Indigo/Violet، حدود دقيقة، بطاقات كثيفة، وCoral CTA محدود.

## التشغيل
1. ارفع الملفات إلى GitHub أو افتح `index.html` مباشرة.
2. يعمل الدخول التجريبي: `admin` / `1234`.
3. البيانات الحالية تحفظ تلقائيًا في `localStorage` حتى لا تضيع عند إغلاق الصفحة.
4. لتوصيل قاعدة بيانات حقيقية متعددة الهواتف، نفّذ `supabase.sql` داخل Supabase SQL Editor ثم اربط API في `app.js`.

## PDF
- يعتمد على html2canvas + jsPDF.
- التصدير يصور صفحة التقرير كاملة، لذلك العربية وRTL تظهر كما تراها في التقرير بدل الاعتماد على خطوط PDF خام.
- التصدير يدعم عددًا غير محدود عمليًا من السجلات، ويقسّم التقرير على صفحات A4 تلقائيًا.
- من العقارات: حدّد أكثر من عقار ثم «تصدير المحدد PDF».
- من التقارير: «تصدير الكل PDF» أو «تقرير العملاء».

## ملاحظات مهمة
النسخة الحالية جاهزة كواجهة وتشغيل محلي. ملف Supabase منفصل لتأسيس الجداول. قبل فتح البيانات للعامة في الإنتاج، يجب استبدال سياسات RLS التجريبية بسياسات Auth مقيدة بالمستخدمين.
